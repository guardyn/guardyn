# .well-known Directory

This directory contains security contact information following RFC 9116 standard.

## 📄 Files

### security.txt

Security contact information for vulnerability disclosure.

- **Purpose:** Provides security researchers with contact information
- **Standard:** RFC 9116 (https://www.rfc-editor.org/rfc/rfc9116.html)
- **URL:** `https://guardyn.co/.well-known/security.txt`

### Contents

- Contact email: security@guardyn.co
- Response time: Within 48 hours
- Preferred languages: English, Ukrainian, Russian

## 🔒 Reporting Security Vulnerabilities

If you discover a security vulnerability:

1. **Email us:** security@guardyn.co
2. **Include:** Detailed description, steps to reproduce, impact assessment
3. **Wait for response:** We will respond within 48 hours

**Please do NOT:**
- File public GitHub issues for security vulnerabilities
- Disclose vulnerabilities publicly before we respond

## 📚 RFC 9116 Compliance

Required fields:
- ✅ `Contact:` - Email address for security reports
- ✅ `Expires:` - Date when this file should be updated
- ✅ `Canonical:` - Authoritative URL for this file
- ✅ `Preferred-Languages:` - Languages we can handle
